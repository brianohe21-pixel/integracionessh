1. Resumen ejecutivo

Telcored SAS opera su plataforma omnicanal serverless desplegada en Amazon Web Services (AWS). Funciona como capa empresarial sobre la API oficial de Meta WhatsApp Business Platform (Cloud API), con panel web, inbox multiagente, automatizaciones, contact center y canales adicionales (SMS Telcored, email, voz, Telegram, Instagram).

La arquitectura separa: canal oficial Meta, plataforma Telcored SAS, identidad corporativa (Microsoft Entra ID) y controles de seguridad mediante AWS WAF, AWS KMS (CMK), TLS y RBAC.

Servicios AWS WAF / KMS / Seguridad Cifrado en tránsito (TLS) Cifrado WhatsApp (E2E) Servicios externos

Principios de diseño Telcored SAS

  • Serverless first: ~50 funciones Lambda; telephony-gateway en ECS Fargate.
  • Multi-tenant: aislamiento por tenant en DynamoDB con JWT Cognito.
  • Event-driven: SQS FIFO + EventBridge Scheduler.
  • Seguridad en capas: WAF, TLS, JWT, RBAC, Secrets Manager, CMK (KMS).
  • Sin WhatsApp Web libre: solo Cloud API oficial de Meta.

3. Flujo de conversación cifrada — Cliente ↔ Meta ↔ Telcored SAS

Toda conversación WhatsApp transita por capas de cifrado en cada salto. Entre el teléfono del cliente y los servidores de Meta aplica el cifrado de extremo a extremo (E2E) del protocolo Signal/WhatsApp. Entre Meta y la plataforma Telcored SAS, y dentro de AWS, todo el tráfico usa TLS 1.2+ y los datos en reposo se protegen con AWS KMS (CMK).

Nota de seguridad Telcored SAS: El tramo Cliente ↔ Meta está protegido por el cifrado E2E nativo de WhatsApp (protocolo Signal). Telcored SAS no tiene acceso al contenido cifrado E2E en tránsito hacia el dispositivo del cliente; recibe y envía mensajes a través de la Cloud API oficial de Meta bajo TLS, con validación HMAC de webhooks, almacenamiento cifrado con CMK y acceso restringido por RBAC.

5. Seguridad — WAF, KMS y controles Telcored SAS

5.1 AWS WAF v2

  • Web ACL en API Gateway HTTP y ALB telephony
  • Rate-based rules en /webhook y /v1/*
  • AWS Managed Rules: OWASP Core, Known Bad Inputs
  • Geo match e IP allowlist corporativa
  • Logs WAF → CloudWatch (cifrado KMS)

5.2 AWS KMS — CMK Telcored

  • CMK: alias/chatbot-platform-{env}-cmk
  • DynamoDB SSE-KMS (conversaciones)
  • S3 default encryption SSE-KMS
  • SQS SSE-KMS en colas FIFO
  • Secrets Manager con CMK dedicada
  • Rotación automática de claves
